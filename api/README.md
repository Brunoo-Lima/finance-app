# API da Mastercash 

## O que é

O MasterCash é uma API REST desenvolvida com Java e Spring Boot 
para gerenciamento de finanças pessoais.

Seu objetivo é facilitar o controle financeiro, permitindo que os 
usuários registrem e gerenciem suas receitas e despesas, 
acompanhem seus saldos e organizem suas metas financeiras.

A API é responsável por gerenciar as regras de negócio, 
autenticação, segurança e persistência dos dados, oferecendo uma 
estrutura organizada para o gerenciamento financeiro.

## Problema que resolve

O projeto surgiu de uma necessidade pessoal: 
**ter mais controle sobre minhas finanças e entender 
exatamente para onde meu dinheiro está indo.**

No dia a dia, é fácil perder o controle dos pequenos gastos e, 
ao final do mês, não saber exatamente como o dinheiro foi utilizado.

Com essa aplicação, consigo registrar minhas movimentações 
financeiras, acompanhar minhas receitas e despesas e ter uma visão 
clara da minha situação financeira.

Atualmente, utilizo o projeto sempre que realizo alguma movimentação. 
Assim, ao final de cada mês, consigo entender quanto gastei, 
onde gastei e por que estou com determinado saldo.
